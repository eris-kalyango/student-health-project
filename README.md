## Social Media & Student Health
# Overview
This project analyzes the relationship between social media usage and student health using data analysis techniques.
## Objectives
Analyze students' social media usage.
Explore factors related to student health.
Identify patterns and relationships in the data.
Create visualizations to communicate findings.
## Tools Used
Python,
Pandas,
Matplotlib,
Seaborn,
Jupyter Notebook
## Dataset
The dataset contains information about students' social media usage and health-related factors.
## Analysis
The project includes:
Data cleaning
Exploratory Data Analysis (EDA)
Descriptive statistics
Data visualization
Correlation analysis
Key findings
## Conclusion
The analysis provides insights into how social media usage may be associated with different aspects of student health.
